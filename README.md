# Paper-trading dashboard (automatisch gegenereerd)

Dit is een **automatisch gegenereerd dashboard** van een *paper-trading*-experiment: **alleen virtueel geld**,
geen echte orders, geen wallet, geen financieel advies. De pagina wordt periodiek overschreven; deze repo bevat
bewust alleen `index.html` (geen code, geen data, geen sleutels).

Auto-generated paper-trading dashboard (virtual money only). Not financial advice.
